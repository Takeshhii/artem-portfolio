# Artem Tarasov — Portfolio (legacy)

Source for my personal site — bilingual (RU/EN), vanilla HTML/CSS/JS, no build
step, opens by double-clicking `index.html`.

Hero, skills, case studies, gallery, a career timeline, and a print-to-PDF
résumé (`Ctrl+P`, dedicated print stylesheet). Every string of copy lives in
JS data arrays at the top of `script.js` rather than in the markup.

**Status:** this is the current live site's source, but it's being replaced by
a new build. Kept here as-is rather than polished further, since the effort is
going into the replacement instead.

```
index.html     markup for every section
styles.css     design tokens, layout, print stylesheet
script.js      copy (RU/EN), rendering, language switch, form validation
images/        photos + case study assets
```
